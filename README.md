# Data Science Portfolio

A comprehensive portfolio showcasing data science projects, machine learning implementations, and interview preparation materials.

## Structure

### 1-Notebooks/
Practical implementations and exploratory data analysis for various machine learning algorithms:
- **1.1-Linear-Regression**: Linear regression fundamentals
- **1.2-Logistic-Regression**: Classification with logistic regression
- **1.3-Naive-Bayes**: Probabilistic classification
- **1.4-Random-Forest**: Ensemble learning methods

### 2-Core-Notes/
Comprehensive theoretical notes and interview preparation materials covering:
- Data science interview fundamentals
- Mathematical foundations (calculus, gradient descent)
- Algorithm theory and implementations
- Quick reference for technical interviews

### 3-Specialized-Domains/
Advanced topics and domain-specific projects:
- **NLP-Text-Classification**: Natural language processing and text classification projects

## Getting Started

Each notebook folder contains:
- `notebook.ipynb` - Code implementations with EDA, feature engineering, model training, and evaluation

Each theory folder contains:
- `.md` files - Detailed explanations and notes for quick reference
