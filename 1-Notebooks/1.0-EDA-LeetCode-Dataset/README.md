# Leet Code Dataset

Exploratory data analysis and problem-solving using LeetCode datasets.

## Files

- `EDA_Assignment_Question.ipynb` - Exploratory Data Analysis notebook

## Setup

1. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the notebook in Jupyter or VS Code
